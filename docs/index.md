# Garterscopic

Garterscopic is a declarative lightweight static site generator built in Go.

This documentation covers the project structure, component system, layouts, and the build workflow.

## Why use Garterscopic?

- Plain HTML, YAML, Markdown, and CSS
- No Node.js runtime required
- Single-binary deployment model
- Simple, predictable filesystem structure
- Fast builds for static content sites

## Quick start

```bash
garterscopic init my-site
cd my-site
garterscopic build
```
