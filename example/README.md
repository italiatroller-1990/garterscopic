# Example

Built with Garterscopic.

## Commands

```bash
garterscopic check   # Validate the project
garterscopic build   # Build the site
garterscopic dev     # Start development server
garterscopic graph   # Show page/component structure
garterscopic clean   # Remove generated files
```

This example exercises the optional features: sitemap, RSS feed,
taxonomies (tags + categories), pagination, and broken-link checking.
Slots are used in the card component (`components/card.html`).
