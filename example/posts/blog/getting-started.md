# Getting Started with Garterscopic

Garterscopic makes it easy to build static sites.

## Installation

Just download the binary and you're ready to go.

## Creating Your First Page

Use the CLI to create a new page:

```bash
garterscopic new page about
```

## Creating a Post

Posts support sections and tags:

```bash
garterscopic new post blog/my-first-post
```
